# Roadmap

1. **Local discovery:** explicit incremental sync, evidence-backed Neo4j graph, local CLI questions,
   Mermaid export, and synthetic multi-repository examples.
2. **MCP:** read-only architecture, dependency, evidence, and status tools for compatible assistants.
3. **Impact analysis:** reverse dependencies and architecture comparisons between source versions;
   distinguish potential reachability from confirmed operational impact.
4. **Documentation:** architecture descriptions and diagrams regenerated from synchronized evidence.
5. **Additional sources:** read-only AWS inventory and external architecture/operations documents;
   distinguish declared, inferred, and observed architecture.
6. **Optional interfaces/providers:** browser-based graph exploration and an explicitly configured OpenAI provider.

Future work: AST-based language extractors, more infrastructure providers, endpoint reconciliation,
semantic retrieval, and stronger evidence validation. These are not promised as complete MVP capabilities.
